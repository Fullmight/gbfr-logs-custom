GBFR Logs Awa Edition - Portable
================================

1. Extract the entire ZIP to a writable folder.
2. Start Granblue Fantasy: Relink.
3. Run "GBFR Logs Awa Edition.exe" and approve the administrator prompt.

Keep the EXE, hook.dll, assets, and lang folders together. The logger creates
logs.db beside the executable, so moving that file with the application keeps
your saved encounters. Do not run the program from inside the ZIP preview.

The Microsoft Edge WebView2 Runtime is required. It is normally included with
current Windows installations. If the application does not open, install the
Evergreen WebView2 Runtime from Microsoft:
https://developer.microsoft.com/microsoft-edge/webview2/

Automatic updates are disabled. Replace the extracted application files with a
new portable release when updating, while retaining logs.db if you want to keep
your encounter history.
